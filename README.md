# 🌿 Garden AI Botanist

**Local-First. Organic. Intelligent.**

A privacy-focused gardening assistant powered by Gemini AI. It helps you cultivate a thriving garden with specialized organic advice, plant diagnosis via computer vision, and real-time weather intelligence—all without harvesting your data.

## ✨ Key Features

- **🤖 AI Botanist Persona**: Organic gardening expert for chat and advice.
- **👁️ Plant Diagnosis**: Upload photos to identify plants or diagnose diseases instantly.
- **📍 Local Intelligence**: Real-time, location-based weather tips (Geolocation API).
- **⚡ Smart Caching**: Local-first architecture for instant responses and offline capability.
- **📱 Responsive**: Optimized for all devices.

## 🚀 Quick Start

1.  **Install**: `npm install`
2.  **Setup**: Copy `.env.example` to `.env` and add your `GEMINI_API_KEY`.
3.  **Run**: `npm run dev`

Visit [http://localhost:4321](http://localhost:4321) into your garden.

## 🛠️ Stack
Built with [Astro](https://astro.build), [React](https://react.dev), [Tailwind CSS](https://tailwindcss.com), and Google Gemini.
